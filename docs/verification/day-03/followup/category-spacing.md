# 최대 글자 카테고리 여백 — 2026-11-17

사용자 피드백: “아래쪽 카테고리에서 도서비, 운동비가 간격이 없어져.”

## 원인과 변경

Device Hub Chagok M09 Mini/iOS27.2, Dark/Text Size11에서 수정 전 화면을 확인했다. 카드 간 gap10은 남아 있었지만 flex:1로 세 카드가 같은 줄의 좁은 폭을 나눴고 좌우 padding이 없어 확대된 도서비/운동비 글자가 테두리에 붙고 줄바꿈됐다. [수정 전](category-before.png).

BenefitCategoryList 한 파일에서 카드 기준 폭을 96×fontScale로 정하고 flexWrap으로 폭이 부족하면 다음 줄에 배치한다. 좌우 padding12와 텍스트 가운데 정렬을 추가했다. 글자 배율 제한·내용 생략·고정 높이는 추가하지 않았다. 홈과 복지 안내가 같은 컴포넌트를 사용한다. API·캐시·DB·인증 코드는 변경하지 않았다.

시작 시 git status/diff/cached 확인. 기준은 `/tmp/chagok-category-baseline.diff`, 변경 전 컴포넌트는 `/tmp/chagok-category-before.tsx`. 기존 미커밋 변경을 보존하며 commit/push/PR/staging은 하지 않았다.
