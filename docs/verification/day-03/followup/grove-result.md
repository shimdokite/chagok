# 그로브 연결 후 실제 계정 검증 — 2026-11-17 KST

사용자가 본인 계정과 그로브 연결을 명시적으로 선택한 뒤 로컬 chagok DB에 소속과 2026-11 샘플 신청 3건을 추가했다. **실제 iOS 홈·내역·상세·정책과 요청 시간 초과→재시도 복구를 확인했다. D3-04는 충족, D3-07은 미검증이다.**

## 범위·환경

앱 코드 변경 없이 기존 seed를 실행했다. 수정 문서는 이 결과, day-03 최신 요약, 이전 후속 결과의 최신 링크, 수동 확인, 최신 PR/커밋 초안이다. 증거 이미지 3개와 관련 테스트 로그를 추가했다. 시작 시 git status/diff/cached diff 확인, 기준 diff는 `/tmp/chagok-grove-link-baseline.diff`에 보관했다. 기존 미커밋 구현·컨벤션 변경을 보존했다. commit·push·PR·staging은 하지 않았다.

환경: macOS, 프로젝트 Node v24.22.3, PostgreSQL localhost:55432/chagok, 기존 Next 서버 localhost:3000, Device Hub Chagok M09 Mini/iOS27.2, Light/Text Size3. 실제 Google 로그인은 사용자가 앞서 수행했다. 웹 미리보기 localhost:8082는 네이티브 Google 로그인을 지원하지 않아 이 검증을 대체하지 않는다. 새 화면 코드 변경은 없으며 기존 실제 앱에서 확인했다.

## 직접 실행한 검증 — 5그룹

1. **연결·DB 확인:** Node24 `--env-file=apps/web/.env.local --experimental-strip-types packages/api/scripts/benefits-seed.ts 2026-11 <확인된 User.id> sample-grove` exit0, `Membership link: true`. 문서에는 개인 ID 원문을 저장하지 않았다. 기존 레코드를 덮어쓰지 않는 seed이며 기존 샘플 fixture도 보존한다. `MODULE_TYPELESS_PACKAGE_JSON` 경고는 남아 있고 실행 실패는 아니다. 후속 Prisma 읽기 assertion exit0: SUBMITTED15000/APPROVED20000/REJECTED30000, 총3건, 한도100000−15000−20000=65000.
2. **실제 iOS 조회:** 미소속 홈에서 새로고침 후 그로브와 “개발용 샘플 회사 · DB 조회 데이터” 표시. 홈 사용가능65000/검토중15000/승인20000/총100000 및 최근2건. 내역 전체3건, 반려 필터1건30000, 상세에 사용일2026-11-08·반려 사유·첨부 준비중. 정책 한도100000/식비·도서비·운동비. 각 화면에서 10월로 이동해 정책 없음과 신청 내역 없음 구분. 접근성 버튼으로 탐색했으며 직접 터치/스크롤 전수 검증과는 구분한다. [홈](ios-grove-home.png), [반려 상세](ios-grove-rejected.png).
3. **네트워크 시간 초과·복구:** lsof로 3000 포트 PID74713과 cwd `apps/web`을 확인한 뒤 해당 프로세스에 SIGSTOP. Python finally에서 40초 후 SIGCONT 자동 재개(exit0). 정지 중 앱 새로고침→“새로고침 중”→연결 확인/이전 정보 최신 아님 안내와 “다시 시도” 표시. ## 사용자가 직접 확인할 항목

- **다른 계정 격리:** 현재 앱에서 로그아웃→다른 본인 테스트 Google 계정으로 직접 로그인. 이전 그로브 금액/신청이 잠시라도 나타나지 않아야 한다. 미소속이면 등록 안내가 나와야 한다. 두 번째 계정이 없으면 미검증 유지. 현재 계정은 검증을 위해 로그인 상태로 보존했다.
- **최대 글자 직접 스크롤:** Device Hub Appearance Dark/Text Size11에서 홈·내역·반려 상세·정책 본문 끝까지 직접 스크롤. 긴 사유/카테고리와 하단 버튼 접근 확인 후 Light/3으로 복원. 앞선 도구의 noWindowsAvailable 때문에 직접 스크롤은 아직 미검증이다.
- **기본 빌드:** 일반 터미널에서 프로젝트 Node24 PATH로 `npm run build:web` 실행. 이전 에이전트 실행은 CSS worker 포트 바인딩 EPERM으로 실패했다. 이번에는 재실행하지 않았다.
- **Android:** SDK/에뮬레이터 또는 기기가 준비된 환경에서 실행. 기존 JS export 성공은 실제 실행을 대체하지 않는다.

명령과 상세 절차는 [수동 확인](../../../manual-checks.md#3일차-미검증-후속--2026-11-17)을 따른다. 이번 실제 계정 홈/내역/정책 및 시간 초과 복구를 사용자에게 다시 수행하도록 요구하지 않는다.

## 사이드이펙트

사용자가 승인한 계정의 그로브 Membership 및 샘플 Claim3건은 로컬 DB에 남겨 직접 확인할 수 있게 했다. 기존 계정/세션/신청 삭제나 회사 강제 이동은 하지 않았다. 런타임·스키마·의존성 변경 없음. 개발 서버는 일시 정지 후 자동 재개했고 정상 앱 재조회까지 확인했다. 서버 정지 구간에는 다른 로컬 요청도 지연될 수 있었다. 표시 설정은 변경하지 않았다.
