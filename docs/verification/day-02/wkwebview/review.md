# WKWebView 후속 독립 검토

2026-11-16, 별도 문맥의 읽기 전용 검토. 이번 문서·증거와 관련 bridge/runtime 경로만 검토했으며 기존 인증/UI 전체 변경을 다시 리뷰한 결과는 아니다.

판정: 후속 검증 기록 승인 가능. Critical/Important/Minor 지적 없음. 실제 PR·병합 승인이 아님.

- 사용자 Option+Tab/Space 확인과 Enter 미실행·CSS ring 촬영 부재를 구분한 서술이 정확하다.
- 정상10회·연속5회·서버 복구·왕복20/20·reload 취소가 JSON/AX/화면과 일치한다. 첫 ready=false는 로딩 중 관찰이고 최종 ready=true이며, 취소 실험의 status와 summary도 구분했다.
- 소스의 타이머 해제/측정 취소와 기존 테스트가 설명에 부합한다. 모든 이벤트 경합이 없다고 확대 주장하지 않았다.
- 59통과1EPERM 실패→권한 허용 후60통과, 타입/웹 빌드 로그를 확인했다. 리뷰어가 테스트를 재실행한 것은 아니다.
- 초기/현재 소스79개·의존성·과거 PR 기록·OAuth/성능 원본 보존, staged 비어 있음. 증거의 토큰/JWT/DB 자격증명/개인키 패턴 일치 없음.

## 검토자가 판단하지 않은 범위와 최종 처리

| 범위 | 최종 처리·근거·비용 |
| --- | --- |
| 기존 인증/UI 전체 구현 | 이번 런타임 변경 없음. 기존 검증/독립 리뷰는 역사 기록으로 유지하며 이번 리뷰가 이를 재실행한 것으로 주장하지 않음 |
| 과거 timeout 원인·모든 이전 revision 경합 | 원인 미확정/임의 순서 강제 주입 미실행으로 유지. 드문 실패가 남을 가능성을 최종 결과에 명시 |
| 실기기·Android·Release·스크린리더·Enter | 이번 대상 환경 밖의 미검증으로 유지. simulator 결과로 일반화하지 않음 |
| CSS ring 실제 모양 | 사용자 키보드 포커스/Space 확인으로 W1 동작 판정. 링 모양의 독립 캡처 증거는 없다고 명시 |
| 최종 초안·document-check | 리뷰어의 최초 열람 뒤 생성된 부분은 주 작업자가 형식/링크/실행 로그/해시와 대조. 리뷰어 검토 완료로 표시하지 않음 |
| 로컬 학습 | 비공개 로컬 문서로 주 작업자가 갱신/확인. 내용은 이 리뷰나 PR에 복사하지 않음 |

실행 판단: 현재 미커밋 사용자 작업을 보존하여 별도 worktree/commit 없이 진행했다. 결함이 재현되지 않아 추측 수정이나 새 회귀 테스트를 추가하지 않고 기존 관련/전체 검사를 실행했다. 과거 timeout 재발 시 revision별 이벤트 시각을 수집해야 한다. 보류한 Minor는 없다.
