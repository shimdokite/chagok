## 화면과 도구 한계

- iPhone17/iOS27.2와 Chagok M09 Mini가 부팅된 것을 허용 환경의 simctl 목록으로 확인했다. 초기 샌드박스 simctl은 CoreSimulator 연결 권한 오류로 실패했다. 이 실패를 앱 결함으로 처리하지 않는다.
- Device Hub의 iPhone17 화면은 ‘신청 화면을 불러오지 못했어요’와 ‘다시 시도’ 상태다. 서버 종료 상태에서 남은 화면이며 서버 복구 후 사용자의 다시 시도 조작이 필요하다. CUA 좌표 클릭은 `noWindowsAvailable`; AX Raise는 성공했지만 앱 내부 접근성 항목은 제공되지 않는다. 다른 UI 자동화 도구로 우회하지 않았다.
- Chrome은 목록에는 있으나 생성 시 browser unavailable로 실패했다. IAB에서 [신청 미리보기](http://127.0.0.1:3000/apply)를 열어 입력, JPEG/PNG 10MiB 안내, 로그인 앱 전용 안내와 비활성 첨부/제출 버튼을 확인했다. 이는 앱 사진 선택 성공이 아니다.
- 실제 사진을 선택하거나 카메라 권한을 변경하지 않았다. 기기 조작 결과나 사용자 답변을 받기 전 성공으로 기록하지 않는다.
