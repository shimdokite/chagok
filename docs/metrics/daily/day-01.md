## 실제 API 및 실패 복구

이전 브라우저 성공/장애/복구 검증에 이어, 이번에는 iOS 앱에서 성공 → Next 프로세스 종료 → 연결 오류·재시도 안내 → 서버 재시작 → 성공을 직접 확인했습니다. 이는 의도적으로 장애를 만든 기능 검증이며 운영 성공률로 해석하지 않습니다.

WebView도 서버 중단 시 실패/닫기/재시도와 ready 이전 측정 비활성을 확인했습니다. 복구 과정에서 Next가 127.0.0.1 HMR을 403으로 차단하는 문제를 재현했습니다. 해당 개발 호스트만 허용한 뒤 WEB_READY와 실측이 성공했습니다. 외부 테스트 origin은 계속 403입니다.
