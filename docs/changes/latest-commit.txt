docs(repo): 학습 문서 PR 제외와 2일차 추적 제거 절차 명시

배경: 개인 학습 문서를 로컬에 유지하고 향후 PR에서 제외할 정책이 필요하다
변경: ignore 규칙과 작업·기여·PR 안내에 학습 자료 제외, 로컬 보존, 2일차 완료 후 일회성 추적 제거 절차를 추가한다
검증: check-ignore 규칙 일치, 학습 문서 SHA-256 불변, 기존 추적 유지와 학습 경로 staged diff 제외, diff 공백 및 문서 형식 검사 통과. 앱 테스트는 미실행이다
영향: 현재 추적·원격 파일은 제거하지 않으며 기존 로컬 학습 수정은 커밋에서 제외한다. 2일차 구현은 시작하지 않는다
