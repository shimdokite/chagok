docs(repo): PR 본문을 줄이고 간결한 작성 기준 반영

배경: PR의 중복 메타데이터·프롬프트 인용·상세 검증 나열로 핵심 변경을 읽기 어렵다
변경: 요약부터 시작하고 제품 배경·핵심 검증·AC 요약만 남긴다. AGENTS·컨벤션·템플릿과 1일차 PR 문서에 같은 기준을 적용한다
검증: 문서 구조·인용 제거·로컬 링크·검증 항목 수·git diff 공백 검사. 문서만 변경해 앱 테스트는 재실행하지 않는다
영향: 앱 동작·기존 검증 원본은 바뀌지 않는다. 이후 PR에도 간결한 본문 규칙을 적용하며 중요한 미검증 범위는 유지한다
