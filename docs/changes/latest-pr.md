## 요약

복지비 신청 API와 앱 내 웹 폼을 연결했다. 서버가 회사 소속·월 정책·한도·중복을 검증해 신청을 저장하며, 앱에서 동일 요청 재시도와 저장 후 홈·내역 갱신까지 이어진다.

## 내용

사용자 요청 “서버 신청 API, 권한·한도·중복 검증과 테스트”와 “신청 폼 연결”을 반영했다. 인증 토큰은 앱에 유지하고 웹은 제한된 브릿지 계약으로 정책 조회와 신청을 요청한다. 단독 브라우저는 입력 미리보기이며 영수증 첨부는 다음 범위다.

## 변경

- strict 입력 계약과 `benefits.create`를 추가했다. 세션·Membership에서 사용자/회사를 결정하고, Membership 행 잠금 안에서 소속 비교·사용월 정책·대기/승인 합계·잔액을 확인한다.
- nullable `Claim.requestId`와 사용자별 unique index를 추가했다. 같은 키/내용은 기존 결과를 반환하고 다른 내용은 CONFLICT로 거부해 동시 요청·응답 유실 재시도를 처리한다.
- 폼 입력·정책·제출·오류·재시도·성공 상태와 브릿지 연결 세대 검증을 추가하고 신청 본문을 진단 로그에서 제외했다. 앱 캐시를 갱신하며, 발송된 신청은 화면 종료 시 조기 취소하지 않고 8초 상한 안에서 완료 후 무효화한다.
- 서버/폼 회귀 테스트, Chrome·iOS 검증 및 실측 재현 도구·원본·환경 기록을 추가했다.

## 검증

- 서버 D4-S1~S6 및 폼 D4-F1~F6의 구현/검증 결과를 검토했다. 이번 PR 준비 AC·제약은 [전체 검토 기록](https://github.com/shimdokite/chagok/blob/feat/day-04-claim-flow/docs/verification/day-04-pr.md)에 정리했다. 사용자는 4일차 작업 확인 후 게시를 승인했으며 개별 수동 체크 결과를 대신 추정하지 않았다.
- 이번 최종 실제 로컬 DB 포함 `npm test`: **25파일232개 통과, 실패/skip0**. `npm run style:check`:103파일 위반0, `npm run typecheck`:4개 workspace 통과, 웹 webpack production 빌드 통과, 4개 migration 최신. 최초 샌드박스 DB 연결 실패는 로그 보존 후 허용 환경에서 재검증했다.
- 전체 독립 리뷰에서 닫기/저장 경합1건을 재현·수정했다. 회귀 RED2실패/2통과 → 집중22통과, 제한적 재리뷰에서 새 중요 문제 없음.
- 이전 Chrome/iOS 실제 저장·홈 갱신과 각 준비1회+본10회 [실측](https://github.com/shimdokite/chagok/blob/feat/day-04-claim-flow/docs/metrics/daily/day-04.md)을 포함한다. 수치는 이번 취소 수명 보정 전이며 재측정하지 않았다. 두 환경의 준비 시작점이 달라 직접 성능 비교하지 않는다. Android·물리 기기·Release·실제 OS BFCache·전체 키보드 흐름은 미검증이다.
- 명시적 파일 선정과 staged/대상 브랜치 전체 diff 검사로 로컬 학습 자료·인계 메모·생성 타입 경로 변경을 제외한다. 학습 파일은 로컬에 보존하며 비밀값과 관련 없는 변경을 게시하지 않는다. 전체 whitespace 검사의 원본 로그 공백 경고는 보존하고 코드·문서 검사는 통과했다.

## 사이드이펙트 검토

배포 전에 Prisma Client를 생성하고 `20261119000000_claim_request_id` migration을 적용한 뒤 새 서버를 시작해야 한다. 기존 행은 nullable 컬럼으로 보존된다. 앱·웹 계약은 함께 배포하며 구버전 앱은 연결 안내를 보게 된다. 같은 사용자의 신청은 월이 달라도 잠금을 기다리며 이후 승인/정책 변경 기능도 같은 동기화 경계를 검토해야 한다.

8초 timeout/네트워크 유실 뒤 저장 결과는 불명확할 수 있다. 열린 폼은 동일 UUID로 재시도하며 완전 재로드 뒤 초안 영구 복구는 지원하지 않으므로 내역을 먼저 확인한다. 취소 수명 보정은 회귀/타입 검증했으며 새 iOS 실측은 수행하지 않았다. 롤백은 생성 진입점과 폼 제출을 비활성화하고 저장된 신청·요청 키 컬럼을 보존한다.
