## 요약

영수증을 Supabase 비공개 버킷에 저장하고, 신청에 연결되지 않은 파일은 해당 저장소에서만 정리하도록 했다. Android 에뮬레이터와 실제 Supabase에서 확인한 5일차 검증·측정 결과를 함께 기록했다.

## 내용

“Supabase Storage 무료 플랜으로 하자”는 요청에 따라 기존 신청·인증 DB를 유지하고 영수증 원본은 서버에서 전용 버킷으로 전송한다.

## 변경

- 첨부마다 저장 위치를 기록한다. 기존 첨부는 마이그레이션의 기본값 `local`로 보존한다.
- 서버 전용 설정과 원격 업로드·삭제 어댑터, 저장 위치 분리 회귀 테스트, 합성 영수증 검증 스크립트를 추가했다.
- Android의 실제 계정 신청·세션 오류와 원격 버킷 처리 시간을 원시 표본과 함께 기록했다.

## 검증

- 자동 검사 충족. 병합 전 로컬 PostgreSQL을 사용한 전체 테스트 37파일 343개, 스타일 135파일, 타입 검사 4개 워크스페이스와 웹 프로덕션 빌드를 통과했다.
- 원격 저장 충족. 실제 버킷에 업로드한 합성 원본 22개 일치, 공개 URL 익명 읽기 HTTP 400, 미연결 21개 삭제와 연결 1개 보존을 확인했다. 서버 처리 중앙값은 JPEG 281.87ms, PNG 342.94ms였다.
- 웹 서버 연동 충족. 실행 중이던 서버의 최초 업로드는 HTTP 500이었다. 재시작 후 JPEG·PNG 모두 HTTP 201과 원격 원본 일치를 확인했다.
- Android 에뮬레이터 충족. 실제 로그인·첨부 변경·1원 신청, 세션 만료 401과 회사 전환 403 후 복구를 확인했다. 실기기 촬영·권한 복귀·촬영 구간 실측은 미검증이다.

## 사이드이펙트 검토

원격 쓰기 전 DB 마이그레이션, Prisma 클라이언트 재생성, 서버와 정리 CLI 교체가 필요하다. 롤백 시에는 저장 위치별 정리를 지원하는 CLI를 유지하거나 정리를 중지한다. 구버전 CLI는 원격 객체를 남긴 채 DB 행을 삭제할 수 있다. 이번 변경은 서버 저장 경로에 적용되며 화면 변경은 없다.
