## 요약

README를 일차별 작업 보고서에서 프로젝트 소개와 시작 가이드로 재구성했습니다.

## 내용

처음 방문한 사람이 프로젝트 목적·현재 기능·기술 스택·실행 방법을 확인할 수 있도록 정리했습니다. 미확정 내용은 채울 예정으로 표시했습니다.

## 변경

- 프로젝트 소개, 기능, 기술 스택, 설치·실행, 테스트, 폴더 구조, 기여 안내 구성
- 개인 환경·일시적인 서버 상태·승인 이력 제거, 상세 기록은 문서 링크로 연결
- 데모·배포·라이선스와 Android 실행 가이드는 채울 예정으로 표시

## 검증

- README의 로컬 링크·경로와 실행 명령을 실제 파일·npm scripts에 대조
- PR·커밋 문서 형식 및 git diff 공백 검사
- 문서만 변경하므로 앱 테스트·빌드는 재실행하지 않음

## 사이드이펙트 검토

앱 코드·설정과 기존 검증 원본은 변경하지 않았습니다. 문서 변경을 되돌리면 복원할 수 있습니다.
