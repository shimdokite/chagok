## 요약

로컬 학습 자료가 PR에 포함되지 않도록 제외 정책을 추가했습니다. 기존 추적 파일은 2일차 완료 후 PR 준비 시 로컬에 보존하면서 저장소에서 제거하도록 절차를 명시했습니다.

## 내용

학습 문서는 개인 학습용으로 유지합니다. 이미 추적 중인 파일은 ignore 설정만으로 제외되지 않으므로 커밋과 PR 전체 diff를 별도로 확인합니다.

## 변경

- `.gitignore`에 `/docs/learning/` 추가
- `AGENTS.md`·기여 안내·PR 템플릿에 신규·수정 학습 파일 제외와 로컬 보존 규칙 추가
- 2일차 완료 후 한 번 수행할 Git 추적 제거와 현재 안내 링크 정리 절차 명시

## 검증

- `git check-ignore -v --no-index`로 기존·향후 학습 경로의 ignore 규칙 일치 확인
- SHA-256 대조로 로컬 학습 문서 보존 및 기존 추적 유지 확인. 커밋 대상 6개만 선택하고 학습 경로의 staged diff 제외 확인
- `git diff --check`와 문서 형식 검사 통과. 문서·ignore 정책 변경으로 앱 테스트는 미실행

## 사이드이펙트 검토

현재 원격 폴더와 Git 추적 파일을 삭제하지 않았고 2일차 구현도 시작하지 않았습니다. 기존 로컬 학습 수정은 커밋 대상에서 제외합니다. ignore만으로 기존 추적 파일의 게시를 막을 수 없으므로 PR 전 diff 검사가 필요합니다.
